Visão e Filosofia do Sistema

O que é o JARVIS DSS

O JARVIS DSS é um Decision Support System — sistema de apoio à decisão para day trading. Ele não executa ordens. Ele não prevê o mercado. Ele aumenta a qualidade da sua tomada de decisão ao cruzar, automaticamente, quatro fontes de inteligência.

⚡
A Metáfora Correta
Tony Stark (você) é o operador — JARVIS (o sistema) analisa, processa e sugere. A decisão final é sempre humana. Compra, venda e stop são sempre manuais.
Os 4 Pilares do Sistema
📊
Análise Técnica
MT5 screenshots + dados OHLCV em tempo real. Tendência, zonas, suporte/resistência, rompimentos interpretados por IA multimodal.
🧍
Histórico Pessoal
Vault Obsidian + dataset SQLite. O sistema aprende com seus trades reais, seus setups com maior win rate, seu perfil emocional.
📰
Contexto Macro
NewsAPI + Calendário econômico. Notícias relevantes ao ativo, eventos macro (FOMC, CPI, Payroll), sentimento do mercado.
🤖
IA Contextual
Claude API multimodal. Cruza tudo, explica o raciocínio, sugere cenários, nunca promete certeza — trabalha com probabilidade.
O que o sistema FAZ vs NÃO FAZ
✅ O Sistema FAZ
  • Interpreta screenshots do MT5 (tendência, zonas, rompimentos)
  • Usa dados OHLCV, book e preço atual via MT5 API
  • Acompanha notícias relevantes ao ativo analisado
  • Monitora calendário econômico (eventos macro)
  • Cruza tudo com histórico do Obsidian
  • Responde de forma clara e acionável: OPERAR / ESPERAR / NÃO OPERAR / REVISAR CONTEXTO
  • Salva toda análise no Obsidian com raciocínio completo
  • Gera dataset estruturado para futuro ML
  • Calcula Confidence Score com justificativa
  • Identifica cenários alternativos e riscos
❌ O Sistema NÃO FAZ
  • Não executa ordens automaticamente
  • Não prevê preços com certeza
  • Não garante resultados
  • Não substitui gestão de risco humana
  • Não afirma que um trade vai dar certo
  • Não sugere tamanho de posição sem contexto do usuário
  • Não ignora contexto macro em análises técnicas
  • Não contradiz o histórico real sem justificativa
Princípios Filosóficos
  • Clareza sobre completude — prefira resposta simples e precisa a análise exaustiva e confusa
  • Explicabilidade obrigatória — toda sugestão deve ter "por quê" explícito
  • Modularidade como base — cada parte do sistema deve viver e ser testada de forma independente
  • Memória acumulativa — o sistema fica mais inteligente a cada operação registrada
  • Sem magia — ML e IA são ferramentas de apoio probabilístico, não oráculos
  • Evolução incremental — nada é construído antes de ser necessário

Objetivo Emocional do Sistema
O sistema deve transmitir: sofisticação institucional, tecnologia avançada com propósito, luxo discreto — ferramenta de elite. Confiança operacional nascida do histórico real, não de promessas.

Arquitetura em Camadas

O sistema é organizado em 5 camadas funcionais com responsabilidades isoladas. Nenhuma camada acessa recursos de camadas não-adjacentes diretamente.

Camada 0 — Interface
CustomTkinter — Interface Desktop
Chat · Análise · Trades · Histórico · Dashboard · Configurações. Apenas renderiza e envia eventos — zero lógica de negócio.
↓
Camada 1 — Orquestração
AI Decision Orchestrator (core/orchestrator.py)
Coração do sistema. Recebe input → monta contexto completo → decide quais módulos chamar → chama IA → processa output → distribui resultado.
↓
Camada 2 — Módulos (paralelos)
2A: Dados · 2B: Análise IA · 2C: Memória
2A Dados: MT5 API, Screenshot, NewsAPI, Calendário econômico · 2B Análise IA: Vision, OHLCV context, Prompt Engine, Claude API · 2C Memória: Obsidian Writer/Reader, SQLite Dataset, Context Loader
↓
Camada 3 — Saída / Resposta
Confidence Score · Sugestão · Raciocínio · Alertas
Formata e distribui a resposta: → UI, → Obsidian, → SQLite Dataset, → Telegram (fase 2), → TTS (fase 2).
↓
Camada 4 — Aprendizado (Fase Futura)
ML Engine — treinado com dataset → melhora scoring
Treinado exclusivamente com dados do SQLite. Não acessa Obsidian diretamente (Obsidian é qualitativo). Melhora o Confidence Engine com base no histórico real.

Módulos e Divisões

⚖️
Regra Fundamental
Um módulo = uma responsabilidade = um motivo para mudar. Cada módulo pode ser enviado isoladamente para a IA sem precisar de contexto externo. Se precisar de outro arquivo para ser entendido, está mal dividido.
Estrutura Interna de Cada Módulo
# Padrão estrutural de todos os módulos
módulo/
├── __init__.py         # Exporta apenas o necessário (API pública do módulo)
├── *_client.py         # Comunicação com API/serviço externo
├── *_service.py        # Lógica de negócio do módulo
├── *_model.py          # Modelos Pydantic locais (se necessário)
└── (prompts ficam em /app/prompts/, NUNCA no módulo)
Módulos Detalhados
app/core/orchestrator.py
Coração do sistema — orquestra o fluxo completo
  • Recebe: screenshot + ativo + contexto
  • Chama context_builder → contexto completo
  • Chama claude_client → analisa
  • Chama confidence_engine → score
  • Chama obsidian_writer → salva
  • Chama dataset_writer → salva numérico
  • Retorna: AnalysisResult para UI
app/modules/ai/claude_client.py
Comunicação exclusiva com a API Anthropic
  • send_message(messages, system_prompt) → str
  • send_with_image(image_path, prompt) → str
  • stream_response(messages) → AsyncGenerator
  • call_with_retry(func, max_retries=3)
app/modules/market/mt5_client.py
Conexão e extração de dados do MetaTrader 5
  • get_ohlcv(symbol, timeframe, count) → list[OHLCV]
  • get_current_price(symbol) → float
  • get_positions() → list[Position]
  • connect() / disconnect()
app/modules/memory/obsidian_writer.py
Escreve notas estruturadas no vault Obsidian
  • write_analysis(analysis: AnalysisModel) → Path
  • write_trade(trade: TradeModel) → Path
  • write_briefing(briefing: str) → Path
  • write_reflection(trade_path: Path, reflection: str)
app/modules/memory/obsidian_reader.py
Lê e busca notas relevantes do vault
  • find_similar_trades(asset, setup) → list[Note]
  • get_recent_trades(days=30) → list[Note]
  • get_setup_winrate(setup_name) → float
  • search_by_tags(tags: list[str]) → list[Note]
app/core/confidence_engine.py
Calcula e justifica o Confidence Score 0-100
  • Verifica alinhamento técnico (trend + volume)
  • Verifica contexto macro (notícias, calendário)
  • Cruza com histórico similar (win rate)
  • Considera estado emocional registrado
  • Retorna: ConfidenceScore(value, reasons, risks)
app/modules/risk/pre_trade_checklist.py
Checklist pré-operação com validação humana
  • Tendência confirmada no TF maior?
  • Entrada com volume acima da média?
  • Sem evento macro nos próximos 60min?
  • Stop loss definido antes de entrar?
  • Risco dentro do limite da banca?
  • Retorna: ChecklistResult(approved, score, notes)
app/modules/briefing/morning_briefing.py
Resumo matinal automático às 08:30
  • Coleta: macro do dia + calendário
  • Coleta: notícias overnight
  • Coleta: performance da semana (Obsidian)
  • Gera: briefing consolidado via Claude
  • Salva: Obsidian + exibe no dashboard

Validação de Input com Pydantic
from pydantic import BaseModel, Field
from typing import Literal, Optional

class TradeInput(BaseModel):
    ativo: str = Field(min_length=3, max_length=10)
    direcao: Literal["long", "short"]
    entrada: float = Field(gt=0)
    stop: float = Field(gt=0)
    alvo: Optional[float] = Field(default=None, gt=0)
    resultado: Optional[Literal["win", "loss", "be"]] = None
    emocional: Optional[Literal["calmo", "ansioso", "impaciente", "focado"]] = None
    setup: Optional[str] = None
    timeframe: Optional[str] = None

    def calcular_risco(self) -> float:
        return abs(self.entrada - self.stop)

    def calcular_rr(self) -> Optional[float]:
        if not self.alvo: return None
        risco = self.calcular_risco()
        retorno = abs(self.alvo - self.entrada)
        return retorno / risco if risco > 0 else None

import anthropic
import base64
from pathlib import Path
from typing import Optional, AsyncGenerator
from loguru import logger
from app.config.settings import settings
from app.core.exceptions import ClaudeAPIError

class ClaudeClient:
    """Wrapper único para toda comunicação com a API Anthropic."""

    def __init__(self):
        self._client = anthropic.Anthropic(api_key=settings.ANTHROPIC_API_KEY)
        self._model = settings.CLAUDE_MODEL  # "claude-sonnet-4-5"
        self._max_tokens = settings.CLAUDE_MAX_TOKENS  # 4096

    def send_message(
        self,
        messages: list[dict],
        system_prompt: str,
        model: Optional[str] = None,
        max_tokens: Optional[int] = None,
    ) -> str:
        """Envia mensagem e retorna resposta como string."""
        try:
            response = self._client.messages.create(
                model=model or self._model,
                max_tokens=max_tokens or self._max_tokens,
                system=system_prompt,
                messages=messages,
            )
            return response.content[0].text
        except anthropic.RateLimitError as e:
            logger.warning("Rate limit atingido: {}", e)
            raise ClaudeAPIError(f"Rate limit: {e}")
        except anthropic.APIError as e:
            logger.error("Erro Claude API: {}", e)
            raise ClaudeAPIError(f"API error: {e}")

    def send_with_image(
        self,
        image_path: Path,
        prompt: str,
        system_prompt: str,
    ) -> str:
        """Envia imagem + prompt para análise com Claude Vision."""
        image_data = self._encode_image(image_path)
        media_type = self._get_media_type(image_path)

        messages = [{
            "role": "user",
            "content": [
                {"type": "image", "source": {
                    "type": "base64",
                    "media_type": media_type,
                    "data": image_data,
                }},
                {"type": "text", "text": prompt},
            ]
        }]
        return self.send_message(messages, system_prompt)

    def _encode_image(self, image_path: Path) -> str:
        with open(image_path, "rb") as f:
            return base64.standard_b64encode(f.read()).decode("utf-8")

    def _get_media_type(self, path: Path) -> str:
        ext = path.suffix.lower()
        return {
            ".jpg": "image/jpeg", ".jpeg": "image/jpeg",
            ".png": "image/png", ".gif": "image/gif",
            ".webp": "image/webp",
        }.get(ext, "image/png")

from dataclasses import dataclass
from typing import Optional

@dataclass
class RiskCalc:
    banca: float          # capital total
    risco_perc: float     # % de risco por trade (ex: 1.0)
    entrada: float
    stop: float
    alvo: Optional[float] = None

    def valor_em_risco(self) -> float:
        """Valor em reais a arriscar."""
        return self.banca * (self.risco_perc / 100)

    def tamanho_posicao(self) -> float:
        """Quantidade de contratos/ações."""
        risco_por_unidade = abs(self.entrada - self.stop)
        if risco_por_unidade == 0: return 0
        return self.valor_em_risco() / risco_por_unidade

    def risco_retorno(self) -> Optional[float]:
        """R:R ratio (alvo / risco)."""
        if not self.alvo: return None
        risco = abs(self.entrada - self.stop)
        retorno = abs(self.alvo - self.entrada)
        return round(retorno / risco, 2) if risco > 0 else None

    def resumo(self) -> dict:
        return {
            "valor_arriscado": round(self.valor_em_risco(), 2),
            "contratos": round(self.tamanho_posicao(), 2),
            "risco_retorno": self.risco_retorno(),
            "risco_percentual": self.risco_perc,
        }

class AntiFOMOFilter:
    """Detecta entradas potencialmente emocionais/impulsivas."""

    HORARIOS_RISCO = [
        ((9, 0), (9, 35)),   # Abertura — ruído extremo
        ((12, 0), (12, 30)), # Almoço americano
        ((17, 0), (17, 30)), # Fechamento B3
    ]

        self,
        timestamp: datetime,
        last_trade_result: str,
        news_published_minutes_ago: int,
        consecutive_losses: int,
    ) -> FOMOAlert:

        nivel = "BAIXO"

# app/core/confidence_engine.py
from dataclasses import dataclass, field
from typing import List

WEIGHTS = {
    "trend_alignment":   0.25,
    "setup_quality":     0.25,
    "historical_match":  0.20,
    "macro_context":     0.15,
    "market_quality":    0.10,
    "emotional_state":   0.05,
}

@dataclass
class ConfidenceResult:
    score: float               # 0.0 – 100.0
    label: str                 # "BAIXA" | "MÉDIA" | "ALTA" | "MUITO ALTA"
    reasons: List[str] = field(default_factory=list)
    risks: List[str] = field(default_factory=list)
    breakdown: dict = field(default_factory=dict)

class ConfidenceEngine:

    def calculate(self, factors: dict) -> ConfidenceResult:
        """
        factors: dict com chaves = WEIGHTS.keys()
        Cada valor: float 0.0-1.0
        """
        breakdown = {}
        weighted_sum = 0.0

        for key, weight in WEIGHTS.items():
            val = factors.get(key, 0.5)  # neutro se não informado
            contribution = val * weight * 100
            weighted_sum += contribution
            breakdown[key] = round(contribution, 1)

        score = round(weighted_sum, 1)
        label = self._get_label(score)
        reasons = self._build_reasons(factors)
        risks = self._build_risks(factors)

        return ConfidenceResult(
            score=score, label=label,
            reasons=reasons, risks=risks, breakdown=breakdown
        )

    def _get_label(self, score: float) -> str:
        if score >= 80: return "MUITO ALTA"
        elif score >= 65: return "ALTA"
        elif score >= 50: return "MÉDIA"
        else: return "BAIXA"

    def _build_reasons(self, f: dict) -> List[str]:
        r = []
        if f.get("trend_alignment", 0) > 0.7: r.append("✅ Tendência alinhada em múltiplos timeframes")
        if f.get("historical_match", 0) > 0.6: r.append("✅ Setup similar teve bom resultado no histórico")
        if f.get("macro_context", 0) > 0.7: r.append("✅ Contexto macro favorável")
        return r

    def _build_risks(self, f: dict) -> List[str]:
        r = []
        if f.get("trend_alignment", 1) < 0.4: r.append("⚠️ Tendência conflitante entre timeframes")

from pydantic import BaseModel, Field, computed_field
from typing import Literal, Optional
from datetime import datetime

EmocionalType = Literal["calmo", "ansioso", "impaciente", "focado", "eufórico"]
ResultadoType = Literal["win", "loss", "be"]  # be = break-even
DirecaoType  = Literal["long", "short"]

class TradeModel(BaseModel):
    # Identificação
    id: Optional[int] = None
    created_at: datetime = Field(default_factory=datetime.now)

    # Ativo
    ativo: str = Field(min_length=3, max_length=12)
    direcao: DirecaoType
    timeframe: str = Field(pattern=r"^(M1|M5|M15|M30|H1|H4|D1)$")

    # Preços
    entrada: float = Field(gt=0)
    stop: float = Field(gt=0)
    alvo: Optional[float] = Field(default=None, gt=0)
    saida: Optional[float] = Field(default=None, gt=0)

    # Resultado
    resultado: Optional[ResultadoType] = None
    r_realizado: Optional[float] = None

    # Contexto
    setup: Optional[str] = None
    emocional: Optional[EmocionalType] = None
    confidence_score: Optional[float] = Field(default=None, ge=0, le=100)
    ia_suggestion: Optional[str] = None

    # Links
    obsidian_path: Optional[str] = None
    screenshot_path: Optional[str] = None

    @computed_field
    @property
    def risco_por_unidade(self) -> float:
        return abs(self.entrada - self.stop)

    @computed_field
    @property
    def rr_planejado(self) -> Optional[float]:
        if not self.alvo: return None
        return round(abs(self.alvo - self.entrada) / self.risco_por_unidade, 2)

A maioria dos traders perde porque opera contra a tendência do timeframe maior. O Multi-TF Engine garante que o JARVIS sempre contextualiza a análise do timeframe de entrada com os superiores — aumentando significativamente a qualidade do Confidence Score.

# app/modules/analysis/multi_timeframe.py
from dataclasses import dataclass
from typing import Dict

TIMEFRAME_HIERARCHY = {
    "M5":  ["M15", "H1"],
    "M15": ["H1", "H4"],
    "H1":  ["H4", "D1"],
    "H4":  ["D1", "W1"],
}

@dataclass
class AlignmentResult:
    score: float         # 0.0 – 1.0
    aligned: bool
    details: Dict[str, str]
    summary: str

def calculate_alignment(
    entry_tf: str,
    trends: Dict[str, str]  # {"M5": "bullish", "M15": "bullish", "H1": "lateral"}
) -> AlignmentResult:
    context_tfs = TIMEFRAME_HIERARCHY.get(entry_tf, [])
    entry_trend = trends.get(entry_tf, "lateral")

    scores = []
    for tf in context_tfs:
        ctx_trend = trends.get(tf, "lateral")
        if ctx_trend == entry_trend:
            scores.append(1.0)   # alinhado
        elif ctx_trend == "lateral":
            scores.append(0.5)   # neutro
        else:
            scores.append(0.0)   # contra a tendência

    avg = sum(scores) / len(scores) if scores else 0.5
    aligned = avg >= 0.7

    summary = (f"Alinhamento {avg*100:.0f}%: {entry_tf} {'✅' if aligned else '⚠️'} "
               f"{'alinhado' if aligned else 'conflitante'} com {', '.join(context_tfs)}")

    return AlignmentResult(
        score=avg, aligned=aligned,
        details={tf: trends.get(tf, "n/a") for tf in [entry_tf] + context_tfs},
        summary=summary
    )

            self._cleanup_cache,

def calculate_with_ml(
    self,
    factors: dict,
    ml_model,            # modelo treinado
    feature_vector: list # features numéricas alinhadas com FEATURES
) -> ConfidenceResult:
    # Score base da lógica atual
    base_result = self.calculate(factors)

    # Score do modelo ML
    ml_proba = ml_model.predict_proba([feature_vector])[0][1]  # P(win)
    ml_score = ml_proba * 100

    # Blend: 60% lógica atual + 40% ML (quando ML está calibrado)
    blended = base_result.score * 0.6 + ml_score * 0.4

    base_result.score = round(blended, 1)
    base_result.label = self._get_label(blended)
    base_result.reasons.append(
        f"🤖 ML: setups similares tiveram {ml_proba*100:.0f}% de win rate no histórico"
    )
    return base_result

Adaptive Prompt Engine (Sugestão Avançada)

Com dados suficientes, é possível fazer o JARVIS aprender quais partes do prompt são mais influentes para seus resultados específicos — ajustando automaticamente o peso dado a cada fator.

#           78% dos trades deram win vs 52% sem esse fator"

class AdaptivePromptEngine:
    def calculate_factor_lifts(self, trades_df) -> dict:
        """Retorna lift de cada fator sobre win rate base."""
        base_wr = trades_df["resultado_bin"].mean()
        lifts = {}
        for factor in FEATURES:
            high_val = trades_df[trades_df[factor] > 0.7]["resultado_bin"].mean()
            lifts[factor] = high_val / base_wr if base_wr > 0 else 1.0
        return lifts
